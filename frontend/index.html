📊 About Model

Uses YOLOv8n trained on 1,129 X-ray images with Optuna AutoML (72 trials, TPE + MedianPruner).

Full (YOLOv8m): mAP50 90.4% | Lite (YOLOv8n): mAP50 75.8%

100% on-device inference via ONNX Runtime Web (WASM). No data uploaded.

GitHub: zvs808-code/bone-fracture-yolov8
