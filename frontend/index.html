📊 About Model

Detection (YOLOv8m): 多源统一数据集 27k 训练,可复现 manifest,完整审计记录。Box mAP50 0.82 · 灵敏度 96% / 特异度 79%。

Classification (MultiTask Net): Siamese EfficientNet-B3 双输入 + 3 任务头(位置·方向·形态学) + EdgeGuidedAttention 拓扑门控 + Uncertainty-Weighted Loss。位置 acc 92%,方向 acc 86%。

Clinical Expert System: 3 条医学规则 + 4 状态码 + 三语临床文案。不是吐生概率,而是可读的诊断建议 + 风险警示。

100% on-device inference via ONNX Runtime Web · DICOM (.dcm) 支持。任何医学影像都不会被上传。

GitHub: zvs808-code/bone-fracture-yolov8
