# 🦴 Fracture Detector — 교수자용 설치 안내

**학생**: 장호 (202217111)  
**앱**: YOLOv8n 온디바이스 골절 탐지 (ONNX Runtime Web)

---

## ⚡ 가장 빠른 확인 방법 — 브라우저에서 직접 실행

> Node.js 없이도 확인 가능 (CDN ORT 자동 로드).

1. `장호_app(android, or IOS)/www/index.html` 파일을 Chrome/Edge로 열기
2. 단, 로컬 `file://` 에서는 WASM 제약이 있을 수 있으므로 아래 방법 권장:

```bash
# Python 3가 있으면
cd 장호_app(android, or IOS)
python -m http.server 8080
# → http://localhost:8080/www/ 접속
```

---

## 🤖 Android APK 설치

> **`장호_FractureDetector_v1.0.0_debug.apk`** 파일을 Android 폰으로 전송 후:

1. 파일 관리자에서 APK 탭
2. "알 수 없는 출처" 허용 (디버그 빌드)
3. 설치 → 앱 실행
4. X-ray 이미지 선택 → "탐지 실행" → 골절 위치 바운딩 박스 확인

---

## 🖥️ 데스크탑 (Electron)

```bash
cd 장호_app(android, or IOS)
npm install
npm run electron:start
```
